Handleiding

Claude koppelen aan Neo4j

Je zet een knowledge graph op je eigen computer en laat Claude erin kijken. Daarna stel je in gewone taal vragen aan je gegevens, en bouw je samen met Claude een eerste model op.

Wat het oplevert

Neo4j is een database die gegevens opslaat als een graph: dingen (nodes) en de verbanden ertussen (relaties). Een NL-SfB-code die onder een hoofdgroep valt, een bouwdeel dat bij een ruimte hoort, een eis die op een element van toepassing is: zulke verbanden zijn in een graph geen bijzaak maar de kern. Na deze handleiding kan Claude Desktop die graph lezen, en later ook beschrijven.

MCP (Model Context Protocol) is de afgesproken manier waarop Claude met andere programma's praat. De koppeling in het midden is zo'n MCP-server. Je installeert hem niet los: je zet in een instellingenbestand van Claude Desktop hoe hij gestart moet worden, en Claude Desktop doet de rest.

We gebruiken in deze handleiding de koppeling mcp-neo4j-cypher, uit de verzameling van Neo4j Labs. Die gebruiken we zelf dagelijks. Hij heeft een stand waarin Claude alleen mag lezen; daarmee begin je.

Wat je nodig hebt

  • Claude DesktopDe app voor Windows of Mac, die je al hebt. Niet de browserversie: alleen de app kan een programma op je computer starten. Houd hem bijgewerkt via claude.com/download.
  • Neo4j DesktopGratis, voor gebruik door jezelf op één computer. Installeren doe je in stap 1.
  • uvEen gratis hulpprogramma dat de koppeling ophaalt en start. Installeren doe je in stap 4.
  • Drie kwartierHet meeste is wachten op downloads. Je typt twee opdrachten en past één bestand aan.
Op een Mac

Alles werkt ook op een Mac. Waar het anders gaat, staat het in een kader zoals dit.

De namen van knoppen en menu's komen uit de documentatie van Anthropic en Neo4j. In jouw versie kunnen ze iets anders heten of op een andere plek staan. Wat we niet zelf op de nieuwste versie hebben nagelopen, staat erbij als nog niet getoetst.

1

Installeer Neo4j Desktop

  1. Ga naar de downloadpagina van Neo4j: neo4j.com/deployment-center, onderdeel Neo4j Desktop.
  2. Download de versie voor Windows. Neo4j vraagt soms om je naam en e-mailadres voordat de download begint.
  3. Dubbelklik op het gedownloade installatiebestand en klik de stappen door. De standaardinstellingen zijn goed.
  4. Start Neo4j Desktop.
Op een Mac

Dubbelklik op het .dmg-bestand in Downloads, sleep Neo4j Desktop naar de map Apps (Applications) en start het daar. De database zelf wordt op een Mac pas gedownload als je hem voor het eerst nodig hebt; zorg dan voor internet.

Deze handleiding volgt Neo4j Desktop 2 (de installatie-uitleg van Neo4j, Engels). Uitleg die je elders vindt over Desktop 1 klopt niet meer: de schermen zijn anders.

Gelukt? Neo4j Desktop is open en toont een leeg scherm met een knop om een instance te maken.

2

Maak een oefendatabase en start hem

Een instance is een database-server op je computer. Je maakt er één, alleen om te oefenen.

  1. Klik op Get started (de eerste keer) of op Create instance.
  2. Geef de instance een naam, bijvoorbeeld oefenen. Laat de voorgestelde Neo4j-versie staan.
  3. Kies een wachtwoord. Neem een nieuw wachtwoord dat je nergens anders gebruikt. Het komt straks leesbaar in een instellingenbestand te staan. Schrijf het op; je hebt het in stap 6 nodig.
  4. Noteer ook de gebruikersnaam. Die is normaal neo4j.
  5. Klik op Create. De instance krijgt het label New.
  6. Start de instance met de afspeelknop op de kaart. Wacht tot hij draait.
  7. Kijk op de kaart van de instance naar het adres. Het eindigt op :7687. Dat is de poort waarop de koppeling straks aanklopt.

De app open hebben is niet genoeg. De instance moet zelf gestart zijn. En hij draait alleen zolang Neo4j Desktop openstaat. Sluit je Neo4j Desktop, dan stopt de database en kan Claude er niet meer bij.

Even kijken in het Query-venster

Kies op de kaart Connect > Query. Je krijgt een venster waarin je zelf opdrachten aan de database kunt geven. Typ RETURN 1 en druk op de afspeelknop of Ctrl+Enter. Krijg je 1 terug, dan werkt de database. Dit venster is ook handig om straks na te kijken wat Claude heeft gedaan.

Bron: Instance management in de documentatie van Neo4j Desktop (Engels).

Gelukt? De instance draait, en RETURN 1 geeft in het Query-venster 1 terug.

3

Zet de uitbreiding APOC aan

APOC is een uitbreiding van Neo4j. De koppeling heeft hem nodig om Claude de opbouw van je graph te laten zien: welke soorten nodes en relaties er zijn. Zonder APOC kan Claude wel queries draaien, maar niet het overzicht ophalen.

  1. Open op de kaart van je instance het menu […] en kies Plugins.
  2. Kies APOC en klik op Install. Wacht tot de installatie klaar is.
  3. Herstart de instance (stoppen en weer starten), zodat hij APOC laadt.

Nog niet getoetst: de precieze knoppen in het Plugins-scherm van de nieuwste Neo4j Desktop. De documentatie zegt alleen dat je via […] > Plugins uitbreidingen installeert.

Gelukt? In het Query-venster geeft RETURN apoc.version() een versienummer terug in plaats van een foutmelding.

4

Installeer uv en haal de koppeling alvast op

uv is het hulpprogramma waarmee Claude Desktop de koppeling start. Het bijbehorende commando heet uvx: het haalt een programma op en start het, zonder dat je zelf iets hoeft te installeren of bij te houden.

  1. Druk op Windows, typ PowerShell en open Windows PowerShell. Je krijgt een venster met een knipperende cursor.
  2. Plak de opdracht hieronder en druk op Enter. Hij komt van de officiële installatiepagina van uv (Engels).
Plak dit in PowerShell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  1. Sluit PowerShell en open een nieuw venster. Pas dan kent Windows het nieuwe commando.
  2. Plak de tweede opdracht. Die haalt de koppeling op en laat zijn hulptekst zien. Zo staat hij klaar voor Claude Desktop, en weet je dat uv werkt.
Plak dit in PowerShell
uvx mcp-neo4j-cypher@0.6.0 --help

@0.6.0 legt de versie van de koppeling vast. Zo gedraagt hij zich morgen hetzelfde als vandaag. De eerste keer duurt het een halve minuut; uv haalt dan zo'n zestig onderdelen op.

Op een Mac

Open Terminal (via Spotlight: Cmd+spatie, typ Terminal) en plak in plaats van de eerste opdracht:

curl -LsSf https://astral.sh/uv/install.sh | sh

Open daarna een nieuw Terminal-venster en plak dezelfde tweede opdracht als op Windows.

Gelukt? Je ziet een hulptekst die begint met usage: mcp-neo4j-cypher, met daarin onder meer --read-only. Een paar waarschuwingsregels erboven (DeprecationWarning) kun je negeren.

5

Open het instellingenbestand van Claude Desktop

Claude Desktop leest bij het opstarten een bestand met de naam claude_desktop_config.json. Daarin staat welke koppelingen het moet starten.

  1. Open Claude Desktop.
  2. Open Settings via het menu van de app (op Windows het menu linksboven, of je naam linksonder; op een Mac het menu Claude in de menubalk).
  3. Kies in de linkerkolom Developer.
  4. Klik op Edit Config. Er opent een map met het bestand claude_desktop_config.json, of het bestand opent meteen.
  5. Open het bestand met Kladblok: rechtsklik > Openen met > Kladblok.

Zie je geen Developer? In een nieuwere indeling staat het beheer van lokale koppelingen onder Settings > Desktop app, bij Extensions. Je kunt het bestand ook direct openen: druk op Windows+R, typ %APPDATA%\Claude en druk op Enter.

Op een Mac

Het bestand staat in ~/Library/Application Support/Claude/. Open het met TextEdit en kies in het menu Opmaak > Maak platte tekst, zodat er geen opmaak in sluipt.

Bronnen: Connect to local MCP servers en Getting started with local MCP servers (beide Engels).

Gelukt? Het bestand claude_desktop_config.json staat open in Kladblok. Het kan leeg zijn, {} bevatten, of al wat tekst hebben.

6

Zet de koppeling in het bestand

Is het bestand leeg of staat er alleen {}?

Vervang alles door de tekst hieronder. Zet op de gemarkeerde plek het wachtwoord van je oefendatabase uit stap 2, tussen de aanhalingstekens. Sla op met Ctrl+S.

Plak dit in claude_desktop_config.json
{
  "mcpServers": {
    "neo4j-oefenen": {
      "command": "uvx",
      "args": ["mcp-neo4j-cypher@0.6.0", "--transport", "stdio"],
      "env": {
        "NEO4J_URI": "bolt://localhost:7687",
        "NEO4J_USERNAME": "neo4j",
        "NEO4J_PASSWORD": "jouw-oefenwachtwoord",
        "NEO4J_DATABASE": "neo4j",
        "NEO4J_READ_ONLY": "true"
      }
    }
  }
}

Wat er staat

  • neo4j-oefenen: de naam waaronder je de koppeling in Claude terugziet. Kies gerust een andere, zonder spaties.
  • uvx en mcp-neo4j-cypher@0.6.0: start de koppeling die je in stap 4 hebt opgehaald.
  • bolt://localhost:7687: het adres van de database op je eigen computer.
  • NEO4J_DATABASE: de database binnen de instance. Een nieuwe instance heeft er één met de naam neo4j.
  • NEO4J_READ_ONLY op "true": Claude mag alleen lezen. Hoe je schrijven later aanzet, staat bij het eerste gesprek.

Stond er al tekst in het bestand?

Dan heb je al andere koppelingen of instellingen. Vervang dan niets, maar laat het Claude doen in een gewoon gesprek:

Plak dit in Claude

Hieronder staat de inhoud van mijn claude_desktop_config.json, met daaronder een nieuwe koppeling. Voeg de koppeling neo4j-oefenen toe binnen "mcpServers", zonder iets van het bestaande te veranderen, en geef me het hele bestand terug als geldige JSON. [plak hier je huidige bestand] [plak hier het blok hierboven]

Laat daarbij je wachtwoord weg (zet jouw-oefenwachtwoord neer) en vul het pas in Kladblok zelf in.

Bron voor de namen van de instellingen: de uitleg bij mcp-neo4j-cypher (Engels).

Gelukt? Het bestand is opgeslagen. Elke accolade die opent, sluit ook weer, en elke regel binnen een blok eindigt op een komma, behalve de laatste.

7

Herstart Claude Desktop helemaal en controleer

  1. Sluit Claude Desktop volledig af. Op Windows: klik rechtsonder in het systeemvak (bij de klok, soms achter het pijltje ^) met de rechtermuisknop op het pictogram van Claude en kies Quit. Het venster sluiten met het kruisje is niet genoeg: dan blijft Claude op de achtergrond draaien en leest het het bestand niet opnieuw.
  2. Controleer dat Neo4j Desktop open is en je instance draait.
  3. Start Claude Desktop opnieuw en open een nieuw gesprek.
  4. Klik linksonder in het invoerveld op de knop + en ga naar Connectors. Daar staat neo4j-oefenen.
  5. Bekijk de tools van de koppeling. In de alleen-lezen-stand zijn dat er twee.
Op een Mac

Afsluiten doe je met Cmd+Q terwijl Claude actief is, of via het menu Claude > Quit Claude.

Nog niet getoetst: de precieze namen in het menu Connectors van de nieuwste Claude Desktop. Wij zagen bij een eigen inrichting dat de tools pas na een volledige herstart verschenen.

Gelukt? neo4j-oefenen staat bij Connectors, met de tools get_neo4j_schema en read_neo4j_cypher.

Een eerste gesprek

Drie vragen om de koppeling te leren kennen. Claude vraagt de eerste keer dat het een tool gebruikt om je toestemming. Lees wat het wil doen en keur het goed als het past bij je vraag.

Vraag 1: wat staat er in de database?

Plak dit in Claude

Gebruik de koppeling neo4j-oefenen. Haal de opbouw van mijn graph op: welke soorten nodes, relaties en eigenschappen zijn er, en hoeveel nodes zijn er in totaal? Leg in gewone taal uit wat je ziet en welke query je daarvoor gebruikte.

Een nieuwe database is leeg. Claude zal dat ook zo zeggen. Daarmee weet je dat de koppeling werkt.

Tussendoor: schrijven aanzetten

Om iets in de graph te zetten moet Claude mogen schrijven. Doe dit pas als vraag 1 werkte.

  1. Open claude_desktop_config.json opnieuw, zoals in stap 5.
  2. Verander "NEO4J_READ_ONLY": "true" in "NEO4J_READ_ONLY": "false" en sla op.
  3. Sluit Claude Desktop volledig af via het systeemvak (Quit) en start het opnieuw.
  4. Bij Connectors staat nu een derde tool: write_neo4j_cypher.

Klaar met oefenen? Zet het terug op "true". Lezen is de veilige stand om in te werken.

Vraag 2: een paar nodes maken, na jouw akkoord

Plak dit in Claude

Ik wil een klein stukje NL-SfB oefenen in de graph. Maak een node voor hoofdgroep (2-) Ruwbouw en nodes voor de elementen (21) Buitenwanden, (22) Binnenwanden en (23) Vloeren, elk met een relatie naar de hoofdgroep. Gebruik de code als sleutel en zorg dat dezelfde code nooit twee keer kan voorkomen. Laat me eerst de query zien en leg in gewone woorden uit wat hij doet. Voer niets uit voordat ik akkoord geef.

Claude laat een query zien en wacht. Pas als jij “akkoord” zegt, voert het hem uit en meldt het hoeveel nodes en relaties er zijn bijgekomen. Kijk gerust na in het Query-venster van Neo4j Desktop met MATCH (n) RETURN n: je ziet de nodes dan als bolletjes met lijnen.

Vraag 3: een vraag aan je gegevens

Plak dit in Claude

Welke elementen vallen onder hoofdgroep (2-)? Geef ze gesorteerd op code, en laat ook de query zien die je gebruikte, met een korte uitleg per regel.

Je krijgt nu je eigen gegevens terug, opgehaald via de graph. Met de uitleg per regel leer je ondertussen de querytaal van Neo4j lezen. Die heet Cypher.

Veilig werken

  • Een aparte oefendatabaseBegin in een instance die alleen voor oefenen is. Gaat er iets mis, dan verwijder je hem en maak je een nieuwe. Echte gegevens zet je er pas in als je weet wat je doet.
  • Standaard alleen lezenMet NEO4J_READ_ONLY op "true" heeft Claude geen tool om te schrijven, en weigert de koppeling elke query die iets zou veranderen. Zet schrijven alleen aan als je het nodig hebt.
  • Het wachtwoord staat leesbaarIedereen die het instellingenbestand kan openen, ziet het wachtwoord. Gebruik daarom een eigen wachtwoord voor de oefendatabase, nooit een dat je elders gebruikt. Deel het bestand niet en plak het niet met wachtwoord en al in een gesprek.
  • Eerst laten voorlezenVraag Claude bij elke wijziging eerst de query te tonen en in gewone woorden te zeggen wat er verandert, hoeveel nodes het raakt en of het terug te draaien is. Pas daarna geef je akkoord.

Weggooien gaat snel. Eén query kan alles wissen. Een goede gewoonte: laat Claude vóór elke verwijdering eerst tellen wat er weg zou gaan, en kijk naar dat aantal voordat je akkoord geeft.

Als het niet werkt

Eerste hulp bij elke foutmelding: kopieer de melding en plak hem bij Claude met de vraag wat er misgaat. Laat het wachtwoord daarbij weg.

Claude meldt dat de verbinding met localhost:7687 geweigerd wordt

Meestal is de database niet gestart. Neo4j Desktop open hebben is niet genoeg: de instance moet op de kaart als draaiend staan. Start hem met de afspeelknop en vraag Claude het opnieuw te proberen. Draait er een andere instance, dan staat die op dezelfde poort; er kan er maar één tegelijk draaien.

De koppeling staat niet bij Connectors

Sluit Claude Desktop volledig af via het systeemvak (Quit) en start opnieuw. Een venster sluiten is niet genoeg: dan wordt het instellingenbestand niet opnieuw gelezen.

Staat hij er daarna nog niet, dan zit er waarschijnlijk een tikfout in het bestand. Plak de inhoud (zonder wachtwoord) bij Claude en vraag: “Is dit geldige JSON? Wijs de fout aan.”

De koppeling staat er, maar meldt een fout zoals “uvx not found” of start niet

Claude Desktop vindt het programma uvx niet. Zet dan het volledige pad in het bestand. Op Windows staat het meestal op C:\Users\jouw-naam\.local\bin\uvx.exe; typ in PowerShell where.exe uvx om het zeker te weten. In het bestand schrijf je elke backslash dubbel: "command": "C:\\Users\\jouw-naam\\.local\\bin\\uvx.exe".

Op een Mac geeft which uvx in Terminal het pad. Programma's die je via het Dock start, kennen niet altijd dezelfde paden als Terminal. (Op een Mac nog niet getoetst.)

Ik heb het wachtwoord veranderd, maar Claude blijft “authentication failure” melden

Na een paar keer herstarten kunnen oude exemplaren van de koppeling op de achtergrond blijven draaien, met het oude wachtwoord nog in hun geheugen. Sluit Claude Desktop af, open Taakbeheer (Ctrl+Shift+Esc), zoek bij Processen naar mcp-neo4j-cypher, uvx of python, en beëindig die. Of herstart de computer; dat is de zekerste weg.

Claude kan de opbouw van de graph niet ophalen

De tool get_neo4j_schema heeft de uitbreiding APOC nodig. Installeer APOC zoals in stap 3 en herstart de instance. Gewone queries werken ook zonder APOC.

Claude zegt dat het niet kan schrijven

Dat klopt in de alleen-lezen-stand. Zet NEO4J_READ_ONLY op "false" zoals bij het eerste gesprek, en herstart Claude Desktop volledig.

De eerste start duurt lang of loopt vast

Bij de allereerste start haalt uv de koppeling op. Doe stap 4 opnieuw (de opdracht met --help) zodat alles al klaarstaat, en herstart Claude Desktop daarna.

Waar staan de logbestanden?

Claude Desktop schrijft per koppeling een logbestand: op Windows in %APPDATA%\Claude\logs, op een Mac in ~/Library/Logs/Claude. Het bestand mcp-server-neo4j-oefenen.log laat zien wat de koppeling meldde. Bron: Connect to local MCP servers (Engels).

De valkuilen in “Als het niet werkt” zijn de valkuilen waar wij zelf in liepen: een database die niet gestart was, een venster dat dicht ging terwijl Claude bleef draaien, een oud wachtwoord dat bleef hangen.
